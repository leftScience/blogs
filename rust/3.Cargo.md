rust语言是一个先编译 生成可执行文件 在将可执行文件交到没有安装的rust环境的机器里面运行的过程

上一节提到的rustc 只适合一些简单的代码片段的编译，如果遇到大型项目的编译，还需要借助“Cargo”这个工具进行编译

Cargo 是rust的构建系统和包管理工具，他可以下载依赖，构建项目，类似maven

### 创建一个基于Cargo脚手架的项目

```Rust
cargo new hello_cargo
```

#### 常用命令

```Rust
cargo build  //打包 调试构建
cargo build --release  //打包 为发布而构建
cargo run //运行
cargo check //检查编译的错误 比build快

// 添加包
// https://crates.io/   插件仓库
cargo add xxx  //比如 cargo add rand 就是添加一个随机数的库
cargo update  // 更新包 他会升级到小版本的最新版本号  比如 0.2.11 版本 执行update后可能会变成 0.2.31
```
